Theme 1 - Insufficient Information

An observed pattern was that all users:

  1. Were not sure about what the product actually does
  2. How it could benefit them
  3. Found that the information provided on the landing page was misleading
“Oh, I didn’t realize that I had to conduct the interview. I understood that an AI bot would interview the candidate in real-time.”

Suggestions:

  • The copy on the landing page
  • Adding information about the benefits of signing up and using the product
  • Adding information that can support user navigation and user onboarding

Theme 2 - UI Design

An observed pattern was that all users found it difficult to focus on the tasks and crucial details because:

  1. Their attention was drawn to secondary elements such as the delete question button on the interview page.
  2. There was too much information to read at one time.
  3. Icons are located on unexpected and unintuitive places.

“I’m finding it hard to read the question because the delete question button keeps catching my attention.”

Suggestions

  • Changing the visual hierarchy of headers, text, and components.
  • Changing the page layout where relevant.
  • Correcting spacing.
  • Adhere to using icons and UI patterns that users are familiar with.

Theme 4 - Interview Flow

An observed pattern was that users need to prepare an interview script prior to the interview because:

  1. They need to choose the questions with their team and agree on which ones to ask.
  2. They need HR to approve the interview questions in some instances.

“I’am really surprised that I cannot add my own questions. What if my team has something specific that we would like to ask?”

Suggestions

  • Adding functionality that allows users to add their own questions and customize the interview script
  • Adding functionality to add more candidate information, for example allowing users to upload the candidate’s resume
  • Adding more personalization/customization where relevant and possible
